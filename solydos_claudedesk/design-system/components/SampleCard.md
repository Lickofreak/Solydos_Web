# SampleCard

Marco de muestra con pie numerado, como las fichas de laboratorio de una lámina.

- Props: `index` ("01."), `label`, `kind` (`chat` | `core` | `strata`: arte generado) o `children` (tu imagen o captura).
- En grupos de tres, del mismo tamaño. El pie siempre es número + una o dos palabras.
