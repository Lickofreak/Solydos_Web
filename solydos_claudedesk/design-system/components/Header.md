# Header

Barra de lámina: logo, navegación mono, una línea de metadatos y la cápsula principal.

- Props: `links` (máximo 5), `meta` (texto mono, p. ej. "Agentes IA / 2026", visible desde `bp-lg`), `secondary`, `cta`, `homeHref`.
- Fondo `background` con hairline `border`. Bajo `bp-md` la navegación se oculta; el consumidor aporta el menú móvil.
